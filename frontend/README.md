# Frontend de Gymnisfit Clientes

Aplicación Angular standalone para administrar los clientes del gimnasio.

## Desarrollo

```bash
npm install
npx ng serve
```

Abre `http://localhost:4200/` en el navegador. La aplicación consume la API en `http://localhost:3000/api/clientes`.

## Construcción

```bash
npm run build
```

El resultado se genera en `dist/`.
